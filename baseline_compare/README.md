# Whole-CT baselines for joint model V3

This directory contains the three requested baselines: `sybil/`, `deeplung/`,
and `edicnet/`. All three baselines have **completed training/fine-tuning and
final-checkpoint whole-CT inference verification**. Their model directories
contain `final_artifacts.json` and usable weight links. Held-out evaluation is
scheduled separately; training completion does not establish test performance.

## Cohort shared with the running V3 experiment

`cohort.json` is generated by `python -m back_prop.baseline_compare.cohort` from
the actual configuration of V3 job **12616464** and the same V3 data loader.
It includes source SHA256 hashes and physical-nodule/reader identities.

| Split | CT scans | Patients | Retained physical nodules | Valid scan-risk labels |
|---|---:|---:|---:|---:|
| Training | 638 | 630 | 1,599 | 513 (mask-verified) |
| Existing validation | 64 | 64 | 155 | 54 |
| Test | 166 | 166 | 423 | 137 |

- Physical-nodule mean malignancy `<3` is benign; `>3` is malignant; exactly
  `3` is ignored, matching `back_prop/lidc_policy.py` and V3.
- A scan is positive when it has a retained malignant nodule. When it has only
  retained benign nodules plus an ignored nodule, its scan-level loss is masked
  out, as in V3. Its retained nodules can still provide training supervision.
- All 64 eligible validation patients also occur in training. This validation
  split is not used for model selection, threshold tuning, or early stopping.
- Training/test patients are disjoint. No normalization statistics, fitted
  calibrators, GBM fitting, or checkpoint selection may use the test set.
- This endpoint is LIDC reader-derived nodule malignancy, **not biopsy-confirmed
  scan diagnosis or prospective lung cancer incidence**.

`cache_audit.json` verifies all 638 training cases and 1,599 retained nodules.
One ignored nodule in LIDC-IDRI-0909 has an empty reader-vote consensus. The V3
loader skips that empty mask, so this scan has a valid benign scan label. The
effective training scan-label count is therefore 513, versus 512 from CSV-only
screening. The CT is retained. `verify_cache.py --case-key LIDC-IDRI-0909__scan746`
independently confirms identical V3 targets. Validation/test label counts above
are still CSV-screening counts; they have not undergone this full mask audit.

Training checks the frozen manifest and annotation hashes. `prepare.py` caches
canonical full CTs at 1 mm, consensus-derived nodule boxes, and Sybil inputs.
No training CT is silently dropped if preprocessing fails. Successful epoch
audits check the case or sample identities seen by the optimizer.

## Method-specific adaptations

### Sybil

`sybil/model.py` preserves the official R3D18, multi-attention pool and cumulative
risk head; the official checkpoint loads strictly. Fine-tuning updates the last
residual stage, pooling layers and head for three epochs. Earlier encoder stages
and all BN running statistics are frozen. AdamW uses learning rates `1e-5` for
the encoder stage and `1e-4` for pooling/head.

The first original risk logit is adapted to the current LIDC binary endpoint.
After fine-tuning it is **not** a calibrated one-year incidence prediction, and
the original NLST calibrator is not applied. Masked scan BCE and the upstream
spatial/volume attention KL objectives provide supervision. The attention targets
are retained-nodule consensus masks; cancer-side labels are unavailable and that
term is omitted. Inference uses the CT alone.

NIfTI RAS is converted to axial DICOM row/column order. HU windowing, resize,
normalization, spacing resampling and crop/pad follow the official `Serie`
convention, including resize-before-spacing-resampling. Inputs are 200×256×256,
repeated to three channels; CT intensity caches use float16 storage.

### DeepLung

`ported/detector.py` and `ported/classifier.py` retain the official DPN network
structures. Python 2 print syntax is converted; the detector's import-time demo
and debug printing are disabled. The DPN26 detector strictly loads `fd0066.ckpt`.
`train_detector.py` fine-tunes this public detector for five epochs (SGD `.001`,
momentum `.9`, weight decay `.0001`), with the upstream anchor assignments and
hard-negative loss. Every retained nodule is sampled, plus random-background
crops; ignored nodules are protected from negative-anchor supervision. Input is
the full 1-mm CT in DICOM-like ZYX orientation. The adaptation does not require
external LUNA lung masks or use annotation-derived lung cropping.

`train_classifier.py` trains the official DPN92 from random initialization using
`main_nodcls.py`'s 700-epoch schedule (`neptime=2`), batch 16, SGD momentum `.9`
and weight decay `.0005`. Learning rates are `.1/.01/.001` at epochs 0/300/500.
BF16 autocast is used on PRO6000. Mean/std and GBM fitting use training nodules
only. The final depth-1 GBM uses 2,560 DPN features, central 17³ raw pixels, and
diameter, following the original nodule-classification runner.

The subsequent `det2cls.py` stage runs the fine-tuned detector over the same
638 training CTs, then adapts the classifier for 105 epochs (`neptime=.3`):
learning rates `.1/.01/.001` at epochs 0/45/90, followed by a depth-2 GBM.
Proposals match the nearest nodule within `max(16 mm, diameter/2)`, following
the upstream distance criterion; proposals matching ignored nodules are omitted.
Unmatched detections supply negative examples. All 1,599 original GT samples
remain in this adapted stage so detector misses cannot remove any V3 training CT.
Candidate caps and matching rules are fixed before test evaluation.

### EDICNet

Detection uses the paper's ResNet34 RetinaNet and the cited upstream FPN/anchors.
Native CT slices are HU-normalized to `[0,1]`, resized to 608×608, padded to
640×640, and repeated across three channels. Training uses nodule-containing
slices from every retained training CT, Adam `1e-5`, batch 2, and 50 epochs.
BN statistics are frozen. Overlap with ignored nodules suppresses negative-anchor
supervision. `prepare_slices.py` derives actual per-slice boxes from consensus
masks; it does not project a constant 3D box through all slices.

Classification ports the cited Keras HSCNN to PyTorch: four 3D convolutions,
two max-pooling blocks, three semantic branches, and a hierarchical malignancy
head. It uses 52³ patches, dropout `.8`, Adam `1e-3`, batch 6, and 200 epochs.
Semantic loss weights are `.33/.34/.33`. Kernel L2 `.048` follows the cited Keras
runner and applies to convolution/task-base kernels, as in that implementation.

Two material adaptations must be reported when presenting results:

1. UCLA semantic labels are unavailable. LIDC proxies are used: mean axial box
   diameter (≤10 / 10–20 / >20 mm), solid texture (reader mean ≥4), and smooth
   margin (margin ≥4 AND lobulation ≤2 AND spiculation ≤2). Smooth is coded 0;
   other margins 1. These proxies are not the original UCLA clinical labels.
2. The paper uses manual segmentation masks to zero the background of HSCNN
   patches. For an automatic whole-CT baseline, our adaptation uses a box mask:
   annotation boxes during supervised training and detector boxes at inference.
   It must be called an **EDICNet adaptation**, not an exact replication of the
   manually masked classification experiment.

## Whole-CT prediction

`python -m back_prop.baseline_compare.predict --model MODEL --image CT.nii.gz
--checkpoint CLASSIFIER.pt --output prediction.json` is the inference entry point.
DeepLung and EDICNet also require `--detector-checkpoint DETECTOR.pt`; DeepLung
requires `--gbm gbm.pkl`. `predict.sbatch` accepts the same arguments.

The entry point reads only the CT and model artifacts. Annotation files,
consensus masks and GT boxes are not inference inputs. DeepLung processes the
complete 1-mm CT in 96³ windows (64³ core, 16-voxel context); it decodes the
original 5/10/20-mm anchors, uses logit threshold -2 and 3D NMS IoU .1, and
classifies at most 20 highest-scoring candidates. Scan risk is maximum GBM
malignancy probability, or 0 when no candidates are detected.

EDICNet runs RetinaNet on every native CT slice. It converts the predicted 2D
boxes back to 1-mm coordinates, estimates axial proposal depth from maximum
in-plane box size, and constructs the HSCNN input from that predicted box.
Default selection is the single highest-detection-score ROI, as in the paper's
primary-lesion evaluation. `--max-candidates` can explicitly request multiple
ROIs with maximum-risk aggregation; that is a separate configuration and must
not be selected by test results. A scan with no detections receives risk 0.

Whole-CT connectivity smoke **12623237** passed for Sybil and DeepLung, including
20 detected nodules through DPN + a test-only GBM. The initial untrained-head
EDICNet smoke had no candidates; a second check **12623266** used the training
detector checkpoint and successfully ran one detected ROI through HSCNN. These
are integration checks, not final model evaluations. Smoke weights and the
36-sample test-only GBM must not be used as final trained artifacts.

Evaluation uses the same frozen test split for all four models. Labels and

are never prediction inputs, and the V3 bank cannot update during evaluation.
V3 averages scan probabilities over the full frozen Rashomon bank; DeepLung
uses maximum candidate malignancy; EDICNet uses the prespecified single ROI
with highest detection confidence. No thresholds or configurations are tuned.
Confidence intervals use 2,000 paired patient-cluster bootstrap replicates.
